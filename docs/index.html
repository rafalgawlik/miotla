Wolne miejsce w pasku

Zawsze widzisz, ile zostało. Liczba robi się pomarańczowa poniżej 40 GB i czerwona poniżej 20 GB.

⚡

Szybkie sprzątanie

Jedno kliknięcie czyści w 100% odtwarzalne cache (biała lista). Zero pytań, działa też w tle.

🗂️

Pełne sprzątanie w oknie

Checkboxy per pozycja: konkretne emulatory, Archives, stare wersje. Zaznaczasz dokładnie, co usunąć.

👀

Tryb „co zostałoby usunięte” pokazuje wszystko, nie kasując niczego.

Instalacja

Przez Homebrew albo ze źródeł.

Homebrew (zalecane)

brew install rafalgawlik/tap/miotla
brew services start miotla

Apka pojawi się w pasku menu i wstanie po zalogowaniu.

Ze źródeł

git clone https://github.com/rafalgawlik/miotla
cd miotla/app
./run.sh                 # pierwszy raz tworzy środowisko
./install-autostart.sh   # autostart po zalogowaniu

Potrzebny Python 3 (macOS). Skrypt bin/miotla działa też sam z wiersza poleceń.

Nadaj aplikacji Pełny dostęp do dysku (Ustawienia systemowe → Prywatność i ochrona), żeby widziała m.in. Kosz i cache aplikacji.
