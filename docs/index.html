Clean up your Mac with one click

Miotła shows free space in the menu bar and safely removes developer caches — Docker, Gradle, Xcode, Electron apps, npm/Homebrew — that your tools regenerate on their own. All in a window, not a terminal.

What it does

Fast, safe and visible.

📊

Free space in the bar

Always see how much is left. The number turns orange below 40 GB and red below 20 GB.

⚡

Quick cleanup

One click clears fully regenerable caches (an allow-list). No questions, works in the background too.

🗂️

Full cleanup in a window

Per-item checkboxes: specific emulators, Archives, old versions. Pick exactly what to remove.

👀

Preview first, always

The “what would be removed” mode shows everything without deleting a thing.

🧹

Animated broom

The icon sweeps in the bar while a cleanup runs. A small thing, but a nice one.

🔑

System items

Time Machine snapshots and sleepimage — also from the window, with a native admin password prompt.

What Miotła never touches

It deletes only inside your home folder. It never touches your data.

✕
Browsers
Brave, Chrome, Firefox, Safari, Arc, Edge — profiles and data stay.
✕
Messengers
Signal, WhatsApp and their databases are off-limits.
✕
Program configuration
Settings, sign-ins and credentials of your tools and apps are left untouched.
✕
Your work
Documents, source code and project files are never removed.

Install

Via Homebrew or from source.

Homebrew (recommended)

brew install rafalgawlik/tap/miotla
brew services start miotla

The app appears in the menu bar and starts on login.

From source

git clone https://github.com/rafalgawlik/miotla
cd miotla/app
./run.sh                 # first run creates the environment
./install-autostart.sh   # start on login

Needs Python 3 (macOS). The bin/miotla script also works on its own from the command line.

Grant the app Full Disk Access (System Settings → Privacy & Security) so it can see the Trash and app caches.
